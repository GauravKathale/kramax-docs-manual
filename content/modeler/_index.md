Kramaxx Modeler is a desktop application for modeling BPMN and DMN. It allows you to model files located directly on your local file system.

{{< img src="img/kramaxx-modeler.png" title="Kramaxx Modeler" >}}

This is a guide to get you started with modeling BPMN diagrams and DMN decision tables. Make sure to [Install the Kramaxx Modeler]({{< relref "/installation/kramaxx-modeler.md" >}}) first.
